name: Easy Handover

type: preference
---
Every website built by Invictus Faith Studio must be easy to hand over to the client.

**How to apply:**
- Use standard, well-documented stacks (no exotic tooling clients can't maintain).
- Prefer client-owned accounts (their domain, their Cloud/Supabase project, their Stripe, etc.) so ownership transfers cleanly.
- Include clear README / handover docs when scaffolding client projects.
- Surface "easy handover" as a value prop in marketing copy where relevant (Business page, persona pages, pitches).

**Why:** Clients should never feel locked in. Easy handover is part of the studio's trust promise.
